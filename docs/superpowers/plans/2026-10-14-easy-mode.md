# Easy Mode Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Turn Keiro's Easy Mode into a scan-first invoice (scan → check name/qty/price → Add → the camera reopens), with a printable letter-page template, Route/Stores/Reports tabs, and a tour for each mode.

**Architecture:**
- One reader for the Easy Mode flag (`src/utils/easyMode.js`) feeds every place that changes: the tab set (`tabs.js`), the ☰ menu, the invoice screen, the PDF layout and the tour.
- The Easy invoice is a new screen (`EasyInvoice.jsx` + `ScanCheckCard.jsx`) on the existing `useInvoiceForm` hook, with an `easy` option and a few helpers. So numbering, saving, the guest cap, the $0 guard and edit/duplicate prefill are shared, not rewritten.
- The template is a second layout inside `pdfGenerator.js`. Normal mode draws exactly what it draws today.

**Tech Stack:** React 19 + Vite, Vitest + Testing Library (jsdom), jsPDF + jspdf-autotable, html5-qrcode, Capacitor iOS (OTA, no native change).

**Spec:** `docs/specs/2026-10-14-easy-mode-design.md` (approved 2026-10-14). Read it before starting; this plan argues from it.

- **Inline styles only:** colors from `useTheme()` → `const C = dark ? DARK : LIGHT`, the brand color `ACCENT`, static styles in an `s` object at the bottom of the file (CLAUDE.md "How Styling Works").
- **Magic values and storage keys** live in `src/utils/constants.js` (`STORAGE_KEYS`); every key is `inv_`-prefixed and stored JSON-encoded.

- **Drivers only:** store-owner tabs, menu, tour and Settings stay exactly as they are, even if `inv_easy_mode` is `true` in storage.
- **Normal mode stays as it is:** normal-mode tabs and menu are unchanged, normal-mode invoices still require a store name, and normal-mode PDFs draw the same content as today.
- **No database or SQL changes.** `invoices.store_name` is already `not null default ''`.

- **Copy is exactly the spec's wording.** In particular:

  - Stores note: "N invoices have no store. Open one and tap ⋯ → Edit to add it."

```js
/**
 * easyMode.js — the driver's Easy Mode switch (Settings → Easy Mode).
 *
 * One reader for the flag that the tab set, the ☰ menu, the invoice screen,
 * the PDF template and the tour all depend on. Toggling it reloads the app
 * (see EasyModeSetting), so reading it at call time is always current.
 */
import { STORAGE_KEYS } from './constants';

/** Whether Easy Mode is switched on on this device. */
export function isEasyMode() {
  try { return JSON.parse(localStorage.getItem(STORAGE_KEYS.EASY_MODE)) === true; } catch { return false; }
}

/** Easy Mode only shapes the driver app; store owners never get it. */
export function easyModeFor(role) {
  return role !== 'store_owner' && isEasyMode();
}
```

```js
 * overlay that doesn't exist and show a blank screen. Anything else is unchanged.
 */
export function tabTargetFor(tabIds, page) {
  return ALL_TAB_IDS.has(page) && !tabIds.includes(page) ? tabIds[0] : page;
}
```

```jsx
 * EasyModeSetting — Settings → Easy Mode, for drivers.
 *
 * Easy Mode reshapes only the driver app (tabs, menu, invoice screen, PDF
 * template, tour — see docs/specs/2026-10-14-easy-mode-design.md), so store
 * owners don't get a switch that would do nothing. Turning it on or off reloads

import { Section, Toggle } from '../ui/SettingsUI';
import { STORAGE_KEYS } from '../../utils/constants';
import { isEasyMode } from '../../utils/easyMode';

export const EASY_MODE_DESCRIPTION =
  'Scan items to make invoices. Shows Route, Stores and Reports, with Products and Settings in the menu. Hides Home, Store Info, Marketplace, My Listings and Notes.';

export default function EasyModeSetting({ role, C, dark, onChange = () => window.location.reload() }) {
  if (role === 'store_owner') return null;

  function toggle(on) {
    try {
      localStorage.setItem(STORAGE_KEYS.EASY_MODE, JSON.stringify(on));
    } catch {
      return; // storage blocked (private mode): nothing would change after a reload
    }
    onChange(on);
  }

  return (
    <Section title="Easy Mode" C={C} defaultOpen>
      <div style={{ paddingTop: 4 }}>
        <div style={s.row}>
          <div>
            <div style={{ ...s.title, color: C.text }}>Simplified view</div>
            <div style={{ ...s.desc, color: C.textMuted }}>{EASY_MODE_DESCRIPTION}</div>
          </div>
          <Toggle on={isEasyMode()} onChange={toggle} C={C} dark={dark} />
        </div>
      </div>
    </Section>
  );
}

const s = {
  row:   { display: 'flex', alignItems: 'center', justifyContent: 'space-between', gap: 12 },
  title: { fontSize: 14, fontWeight: 600, marginBottom: 3 },
```

```js
// ── Easy Mode template (docs/specs/2026-10-14-easy-mode-design.md §2) ───────
// Anything the driver left empty prints as a labeled ruled line to fill in by
// pen; anything filled prints as text. Only used when invoice.layout is
// 'template' (the default while Easy Mode is on).

/** "Label: value", or "Label: ______" ruled to the field's right edge. */
function templateField(doc, label, value, x, y, right) {
  doc.setFont('helvetica', 'bold');
  doc.setFontSize(10);
  doc.setTextColor(60, 60, 60);
  doc.text(label, x, y);
  const valueX = x + doc.getTextWidth(label) + 6;
  if (value && String(value).trim()) {
    doc.setFont('helvetica', 'normal');
    doc.text(String(value).trim(), valueX, y);
  } else {
    doc.setDrawColor(150, 150, 150);
    doc.setLineWidth(0.6);
    doc.line(valueX, y + 2, right, y + 2);
  }
}

/** The template's Bill To rows. Returns the y of the last row. */
function drawTemplateBillTo(doc, { storeName, customerName, storePhone, storeAddress }, y, margin, pageW) {
  const right = pageW - margin;
  const mid = margin + (pageW - margin * 2) / 2;
  templateField(doc, 'Store:', storeName, margin, y, right);
  templateField(doc, 'Contact:', customerName, margin, y + 22, mid - 10);
  templateField(doc, 'Phone:', storePhone, mid + 10, y + 22, right);
  templateField(doc, 'Address:', storeAddress, margin, y + 44, right);
  return y + 44;
}

/** "Paid by: ☐ Cash ☐ Card ☐ Check   Amount: ____", then Notes. Returns the y below. */
function drawTemplatePaidByAndNotes(doc, notes, y, margin, pageW) {
  const right = pageW - margin;
  doc.setFont('helvetica', 'bold');
  doc.setFontSize(10);
  doc.setTextColor(60, 60, 60);
  doc.text('Paid by:', margin, y);
  doc.setDrawColor(120, 120, 120);
  doc.setLineWidth(0.6);
  doc.setFont('helvetica', 'normal');
  let x = margin + doc.getTextWidth('Paid by:') + 12;
  for (const method of ['Cash', 'Card', 'Check']) {
    doc.rect(x, y - 8, 9, 9);
    doc.text(method, x + 14, y);
    x += 14 + doc.getTextWidth(method) + 18;
  }
  templateField(doc, 'Amount:', '', x + 8, y, right);

  const notesY = y + 26;
  if (!(notes && notes.trim())) {
    templateField(doc, 'Notes:', '', margin, notesY, right);
    return notesY;
  }
  // Typed notes print as text, wrapped to the page width.
  doc.setFont('helvetica', 'bold');
  doc.setFontSize(10);
  doc.setTextColor(60, 60, 60);
  doc.text('Notes:', margin, notesY);
  const notesX = margin + doc.getTextWidth('Notes:') + 6;
  doc.setFont('helvetica', 'normal');
  const lines = doc.splitTextToSize(notes.trim(), right - notesX);
  doc.text(lines, notesX, notesY);
```

```js
/** An invoice's store name, trimmed; '' when it has none (an Easy Mode invoice can). */
export function storeNameOf(inv) {
  return String(inv?.storeName || inv?.store_name || '').trim();
}

/** The later of two invoice dates (as stored, e.g. "October 9, 2026"). */
function laterDate(a, b) {
  const ta = Date.parse(a || '') || 0;
  const tb = Date.parse(b || '') || 0;
  return tb > ta ? b : a;
}

/**
 * The Stores tab's per-store rows: outstanding balance, invoice count, total
 * and last delivery date, biggest balance first. Invoices with no store are
 * not a store — they're counted in `unassigned` (and in the overall total).
 */
export function groupInvoicesByStore(invoices) {
  const map = {};
  const unassigned = { count: 0, outstanding: 0 };
  invoices.forEach(inv => {
    const owed = getStatus(inv) !== 'paid' ? subtotalOf(inv) : 0;
    const name = storeNameOf(inv);
    if (!name) {
      unassigned.count += 1;
      unassigned.outstanding += owed;
      return;
    }
    if (!map[name]) map[name] = { name, count: 0, outstanding: 0, total: 0, lastDate: '' };
    const st = map[name];
    st.count += 1;
    st.total += subtotalOf(inv);
    st.outstanding += owed;
    st.lastDate = laterDate(st.lastDate, inv.date);
  });
  const stores = Object.values(map).sort((a, b) => b.outstanding - a.outstanding || a.name.localeCompare(b.name));
  return { stores, unassigned };
}

/** Revenue per store, biggest first, as [name, total] pairs; no-store invoices skipped. */
export function revenueByStore(invoices, totalOf) {
  const map = {};
  invoices.forEach(inv => {
    const name = storeNameOf(inv);
    if (name) map[name] = (map[name] || 0) + totalOf(inv);
  });
  return Object.entries(map).sort((a, b) => b[1] - a[1]);
}

/** The Stores tab's note about invoices that have no store yet. */
export function unassignedStoreNote(count) {
  return count === 1
    ? '1 invoice has no store. Open it and tap ⋯ → Edit to add it.'
    : `${count} invoices have no store. Open one and tap ⋯ → Edit to add it.`;
}
```
