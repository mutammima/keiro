# Pricing (Free plan + Keiro Pro) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A free plan (Easy Mode + 20 new invoices a month) and Keiro Pro ($4.99/mo or $49.99/yr through Stripe), enforced by the phone and backstopped by the server, without ever losing an invoice.

**Architecture:** Supabase holds the Pro record (`subscriptions`) and a per-month invoice count (`invoice_usage`, kept by triggers on `invoices`) and answers `my_plan()`. The app caches that answer (`src/utils/plan.js`, the one reader), forces free drivers into Easy Mode, stops at 20, and opens Stripe pages that three Vercel Functions create (`api/checkout`, `api/billing-portal`) and confirm (`api/stripe-webhook`). Uploads the server refuses for the limit are held on the phone, never dropped.

**Tech Stack:** React 19 + Vite PWA (inline styles), Supabase (Postgres, RLS, RPC), Vercel Functions (Node.js, Web `Request`/`Response` handlers), Stripe (Vercel Marketplace integration, `stripe` npm SDK), Capacitor iOS (`@capacitor/browser`, `@capacitor/app`), Vitest + Testing Library, PGlite for SQL checks, Playwright for the real screens.

**Spec:** `docs/specs/2026-10-16-pricing-design.md` (approved by the owner 2026-10-16). Read it before any task.

## Global Constraints

- Free = **20 new invoices per local calendar month** for a **signed-in driver** who isn't Pro; Duplicate counts, edits never do, deletes never give one back.
- **Guests and store owners are never limited by the plan** and never see Upgrade (guests keep their 5-entry cap; store owners keep everything).
- Prices shown: **`$4.99` a month**, **`$49.99` a year**, **`save $9.89`**. Stripe price ids live only in server env vars.
- Server backstop: a free account's upload is refused only past **25** new invoices in the **UTC** month, and only invoices whose own `created_at` is in the current UTC month count or are refused. Refusal message: **`KEIRO_FREE_LIMIT`**.
- **Nothing is ever deleted** because of the plan: a refused upload is held on the phone and re-sent once Pro or next month.
- Offline, a cached Pro stays Pro until **3 days** past its paid-until date; no cached answer = Free.
- A free driver is always in Easy Mode; **upgrading never switches modes by itself** (it offers "Switch to normal mode?").
- Secrets (Stripe secret key, webhook secret, Supabase service-role key) exist only in Vercel env vars, read in `api/`; nothing secret ships in `src/`.
- Inline styles only; theme tokens from `src/theme.js`; every message and price in `src/utils/constants.js`.
- Tests need no `.env`; server tests run in Vitest's `node` environment with Stripe/Supabase faked.
- `src/utils/plan.js` reads and writes `localStorage` directly (not `storage.js` / `guestMode.js` / `storageRoom.js`): many existing tests mock those modules with partial factories.
- **CI has no `.env`, and importing `src/services/supabase.js` without it throws** (`supabaseUrl is required.`). `plan.js` and `billing.js` are imported by screens whose tests don't mock Supabase, so they must never import `services/db`, `services/supabase` or `utils/syncQueue` at the top of the file. They load them with `await import(…)` at call time. The final suite run happens with `.env` moved aside.

## Review Focus

1. **Dad's first launch after the update (no cached plan yet)** — he is treated as Free for a moment; a *stale or missing* answer must never persist the Easy Mode flag or a plan note. Only a fresh server answer does. (Task 3: "an error or no session leaves the cache as it was" + "Pro never touches the mode".)
2. **Stripe events across two subscriptions** (cancel, resubscribe, a late "deleted" for the old one) — an active row is never replaced by an older, non-active subscription. (Task 9: "a late event from an old subscription never downgrades an active one".)
3. **An over-limit free driver edits or marks paid an old invoice** — the app's upsert fires BEFORE INSERT; it must pass. (Task 1: "edit at the limit passes".)
4. **Month boundary** — an invoice made offline Oct 31 and uploaded Nov 1 is neither refused nor counted in November; the phone's count resets on the local 1st. (Task 1: "last month's invoice"; Task 3: "starts over on the 1st".)
5. **Return from Stripe lost or slow** (browser closed by hand, webhook > 30 s) — the plan re-reads on `browserFinished` and foreground, "Finishing up…" gives way to "We'll finish this in the background", and the app never shows Pro unless the server said so. (Task 5: "30 s without Pro → finish later".)

```sql
-- ════════════════════════════════════════════════════════════════════════════
-- Keiro — pricing: the Pro record and the free plan's monthly invoice count
-- (docs/specs/2026-10-16-pricing-design.md §3)
--
-- HOW TO RUN: through docs/COWORK_PRICING.md (Supabase Dashboard → SQL Editor).
-- Safe to re-run. Run it BEFORE the app update that turns the limits on.
--
-- subscriptions  — who is Pro: Stripe subscribers (written by api/stripe-webhook
--                  with the service-role key) and the owner's switch (by hand).
-- invoice_usage  — new invoices per account per UTC month, kept by triggers.
-- A free account's upload is refused past 25 in a month (the app stops at 20).
-- Only invoices whose own created_at is in the current UTC month count or can be
-- refused, so a guest's history, a restored backup or last month's offline
-- invoice always uploads. Users read their own rows in both tables, write neither.
-- ════════════════════════════════════════════════════════════════════════════

-- Pricing: who is Pro.
create table if not exists subscriptions (
  user_id                uuid primary key references auth.users(id) on delete cascade,
  source                 text not null check (source in ('stripe', 'manual')),
  status                 text not null default 'active',
  pro_until              timestamptz,                      -- null with source 'manual' = free forever
  interval               text check (interval in ('month', 'year')),
  cancels                boolean not null default false,   -- cancelled: ends at pro_until
  stripe_customer_id     text unique,
  stripe_subscription_id text unique,
  updated_at             timestamptz not null default now()
);
alter table subscriptions add column if not exists cancels boolean not null default false;

create table if not exists invoice_usage (
  user_id uuid not null references auth.users(id) on delete cascade,
  month   date not null,                                   -- first day of the UTC month
  count   integer not null default 0,
  primary key (user_id, month)
);

alter table subscriptions enable row level security;
alter table invoice_usage enable row level security;

drop policy if exists "subscriptions: read own" on subscriptions;
create policy "subscriptions: read own" on subscriptions
  for select to authenticated using (user_id = auth.uid());
drop policy if exists "invoice_usage: read own" on invoice_usage;
create policy "invoice_usage: read own" on invoice_usage
  for select to authenticated using (user_id = auth.uid());

-- Supabase's default privileges open new tables to anon and authenticated.
revoke all on subscriptions from anon;
revoke all on invoice_usage from anon;
revoke insert, update, delete, truncate on subscriptions from authenticated;
revoke insert, update, delete, truncate on invoice_usage from authenticated;
grant select on subscriptions to authenticated;
grant select on invoice_usage to authenticated;

create or replace function is_pro(p_uid uuid)
returns boolean
language sql
stable
security definer
set search_path = public, pg_temp
as $$
  select exists (
    select 1 from subscriptions s
    where s.user_id = p_uid
      and (   (s.source = 'manual' and (s.pro_until is null or s.pro_until > now()))
           or (s.source = 'stripe' and s.status in ('active', 'past_due') and s.pro_until > now())));
$$;

create or replace function invoices_free_limit()
returns trigger
language plpgsql
security definer
set search_path = public, pg_temp
as $$
declare
  v_month date := (date_trunc('month', now() at time zone 'utc'))::date;
  v_used  integer;
begin
  -- Only invoices made this month can be refused: history uploads never are.
  if new.created_at is null
     or (date_trunc('month', new.created_at at time zone 'utc'))::date <> v_month then
    return new;
  end if;
  -- An upsert of an invoice that already exists is an edit: never refused.
  -- (Postgres runs BEFORE INSERT triggers on insert … on conflict do update.)
  if exists (select 1 from invoices i
             where i.user_id = new.user_id and i.invoice_number = new.invoice_number) then
    return new;
  end if;
  if is_pro(new.user_id) then
    return new;
  end if;
  select u.count into v_used from invoice_usage u
   where u.user_id = new.user_id and u.month = v_month;
  if coalesce(v_used, 0) >= 25 then
    raise exception 'KEIRO_FREE_LIMIT'
      using errcode = 'P0001', hint = 'Free plan: 20 new invoices a month.';
  end if;
  return new;
end
$$;

create or replace function invoices_count_usage()
returns trigger
language plpgsql
security definer
set search_path = public, pg_temp
as $$
declare
  v_month date := (date_trunc('month', now() at time zone 'utc'))::date;
begin
  if new.created_at is not null
     and (date_trunc('month', new.created_at at time zone 'utc'))::date = v_month then
    insert into invoice_usage as u (user_id, month, count) values (new.user_id, v_month, 1)
    on conflict (user_id, month) do update set count = u.count + 1;
  end if;
  return null;
end
$$;

drop trigger if exists trg_invoices_free_limit on invoices;
create trigger trg_invoices_free_limit
  before insert on invoices
  for each row execute function invoices_free_limit();

-- AFTER INSERT fires only for rows actually inserted, so an edit never counts.
drop trigger if exists trg_invoices_count_usage on invoices;
create trigger trg_invoices_count_usage
  after insert on invoices
  for each row execute function invoices_count_usage();

create or replace function my_plan()
returns json
language sql
stable
security definer
set search_path = public, pg_temp
as $$
  select json_build_object(
    'pro',             is_pro(auth.uid()),
    'source',          s.source,
    'status',          s.status,
    'pro_until',       s.pro_until,
    'interval',        s.interval,
    'cancels',         coalesce(s.cancels, false),
    'used_this_month', coalesce((select u.count from invoice_usage u
                                  where u.user_id = auth.uid()
                                    and u.month = (date_trunc('month', now() at time zone 'utc'))::date), 0),
    'month',           to_char(now() at time zone 'utc', 'YYYY-MM'),
    'free_limit',      20)
  from (select 1) as one
  left join subscriptions s on s.user_id = auth.uid()
  where auth.uid() is not null;
$$;

revoke execute on function is_pro(uuid) from public, anon, authenticated;
revoke execute on function invoices_free_limit() from public, anon, authenticated;
revoke execute on function invoices_count_usage() from public, anon, authenticated;
revoke execute on function my_plan() from public, anon;
grant execute on function my_plan() to authenticated;
```

```js
/**
 * plan.js — the free plan and Keiro Pro on this phone
 * (docs/specs/2026-10-16-pricing-design.md §1, §3, §4).
 *
 * The one reader for "is this account Pro?" and "how many free invoices are
 * left?". The server's answer (my_plan(), supabase-pricing.sql) is cached with
 * when it was fetched; offline, a cached Pro stays Pro until a few days past
 * its paid-until date, and with no answer at all the account is Free. Only a
 * signed-in driver is ever limited: guests keep their own cap, store owners
 * keep everything.
 *
 * Every screen imports this module, so it stays dependency-light: it reads and
 * writes localStorage directly (many tests mock storage.js / guestMode.js /
 * storageRoom.js with partial factories), and it loads services/db and
 * syncQueue only when it needs them — importing the Supabase client without
 * a configured URL throws, and CI has no .env.
 */
import {
  STORAGE_KEYS, EVENTS, MS_PER_DAY, FREE_INVOICES_PER_MONTH, OFFLINE_PRO_GRACE_DAYS,
  PRO_PRICE, PLAN_COPY,
} from './constants';
import { localMonth } from './invoiceUtils';

function read(key, fallback = null) {
  try { const raw = localStorage.getItem(key); return raw ? JSON.parse(raw) : fallback; } catch { return fallback; }
}
function write(key, value) {
  try { localStorage.setItem(key, JSON.stringify(value)); return true; } catch { return false; }
}
function announce() {
  try { window.dispatchEvent(new CustomEvent(EVENTS.PLAN_CHANGE)); } catch { /* no DOM */ }
}
function isGuestNow() {
  try { return localStorage.getItem(STORAGE_KEYS.GUEST_MODE) === 'true'; } catch { return false; }
}
function isStoreOwner() {
  return read(STORAGE_KEYS.USER_ROLE, 'driver') === 'store_owner';
}
function shortDate(isoString) {
  return new Date(isoString).toLocaleDateString('en-US', { month: 'short', day: 'numeric' });
}

/** The cached my_plan() answer, or null when the server never answered on this phone. */
export function getCachedPlan() {
  const p = read(STORAGE_KEYS.PLAN_CACHE);
  return p && typeof p === 'object' ? p : null;
}

/**
 * Whether a cached answer still means Pro at `now`. Free forever has no end;
 * anything else stays Pro offline until OFFLINE_PRO_GRACE_DAYS past its
 * paid-until date, so a paying driver is never locked out for lack of signal.
 * @param {object|null} plan
 * @param {Date} [now]
 */
export function isProNow(plan, now = new Date()) {
  if (!plan?.pro) return false;
  if (plan.proUntil == null) return plan.source === 'manual';
  const until = Date.parse(plan.proUntil);
  return Number.isFinite(until) && now.getTime() <= until + OFFLINE_PRO_GRACE_DAYS * MS_PER_DAY;
}

export function isPro(now = new Date()) {
  return isProNow(getCachedPlan(), now);
}

/** A signed-in driver who isn't Pro — the only account the plan limits. */
export function onFreePlan(now = new Date()) {
  return !isStoreOwner() && !isGuestNow() && !isPro(now);
}

/** New invoices made this local month: the larger of this phone's count and the server's. */
export function invoicesUsedThisMonth(now = new Date()) {
  const month = localMonth(now);
  const usage = read(STORAGE_KEYS.USAGE);
  const local = usage?.month === month ? Number(usage.count) || 0 : 0;
  const plan = getCachedPlan();
  const server = plan?.month === month ? Number(plan.usedThisMonth) || 0 : 0;
  return Math.max(local, server);
}

export function freeInvoicesLeft(now = new Date()) {
  return Math.max(0, FREE_INVOICES_PER_MONTH - invoicesUsedThisMonth(now));
}

/** Whether a new invoice (Duplicate included) may be made now. Edits are never limited. */
export function canCreateInvoice(now = new Date()) {
  return !onFreePlan(now) || freeInvoicesLeft(now) > 0;
}

/** Counts one new invoice saved on this phone. */
export function recordNewInvoice(now = new Date()) {
  const month = localMonth(now);
  const usage = read(STORAGE_KEYS.USAGE);
  const count = usage?.month === month ? (Number(usage.count) || 0) + 1 : 1;
  write(STORAGE_KEYS.USAGE, { month, count });
  announce();
}

/** "Nov 1": when this month's free invoices come back. */
export function resetDateLabel(now = new Date()) {
  return new Date(now.getFullYear(), now.getMonth() + 1, 1)
    .toLocaleDateString('en-US', { month: 'short', day: 'numeric' });
}

/**
 * After a FRESH answer from the server (never a missing or stale cache): a
 * free driver is moved into Easy Mode for good — so upgrading later never
 * switches modes by itself — with a one-time note; Pro releases uploads held
 * for the limit.
 */
export async function applyFreshPlan(prev, next) {
  if (isStoreOwner() || isGuestNow()) return;
  if (next.pro) {
    const { releaseHeldSyncs } = await import('./syncQueue');
    releaseHeldSyncs();
    return;
  }
  if (prev?.pro) write(STORAGE_KEYS.PLAN_NOTICE, 'ended');
  if (read(STORAGE_KEYS.EASY_MODE, false) !== true) {
    write(STORAGE_KEYS.EASY_MODE, true);
    const hasInvoices = (read(STORAGE_KEYS.LIST, []) || []).length > 0;
    if (!prev?.pro && hasInvoices) write(STORAGE_KEYS.PLAN_NOTICE, 'moved');
  }
}

let inflight = null;

/**
 * Asks the server for this account's plan and caches it. Concurrent calls
 * share one request. Resolves { ok: false } offline, signed out, or before
 * supabase-pricing.sql is run — the cache is left as it was.
 * @returns {Promise<{ ok: boolean, plan?: object }>}
 */
export function refreshPlan() {
  if (!inflight) inflight = fetchPlan().finally(() => { inflight = null; });
  return inflight;
}

async function fetchPlan() {
  const db = await import('../services/db');
  const { data, error } = await db.getMyPlan();
  if (error || !data || typeof data !== 'object') return { ok: false };
  const prev = getCachedPlan();
  const next = {
    pro: data.pro === true,
    source: data.source ?? null,
    status: data.status ?? null,
    proUntil: data.pro_until ?? null,
    interval: data.interval ?? null,
    cancels: data.cancels === true,
    usedThisMonth: Number(data.used_this_month) || 0,
    month: data.month ?? null,
    fetchedAt: new Date().toISOString(),
  };
  write(STORAGE_KEYS.PLAN_CACHE, next);
  await applyFreshPlan(prev, next);
  announce();
  return { ok: true, plan: next };
}

/** Shows the Upgrade sheet (UpgradeHost), optionally with its own title. */
export function openUpgrade(title) {
  try { window.dispatchEvent(new CustomEvent(EVENTS.OPEN_UPGRADE, { detail: { title } })); } catch { /* no DOM */ }
}

/** Shows "You've used your 20 free invoices this month" (UpgradeHost). */
export function openFreeLimit() {
  try { window.dispatchEvent(new CustomEvent(EVENTS.OPEN_FREE_LIMIT)); } catch { /* no DOM */ }
}

/** + New / Duplicate: runs `go` under the limit, otherwise shows the limit sheet. */
export function guardNewInvoice(go) {
  if (!canCreateInvoice()) { openFreeLimit(); return false; }
  go();
  return true;
}

/** The sign-up plan screen's choice: Pro opens the Upgrade sheet once in the app. */
export function rememberPlanChoice(plan) {
  if (plan === 'pro') write(STORAGE_KEYS.UPGRADE_AFTER_SIGNUP, true);
}

/** What Settings → Plan shows for a cached answer. */
export function planSummary(plan, now = new Date()) {
  if (!isProNow(plan, now)) {
    return { label: 'Free', sub: PLAN_COPY.usedLine(invoicesUsedThisMonth(now), resetDateLabel(now)), action: 'upgrade' };
  }
  if (plan.source === 'manual') {
    return { label: plan.proUntil ? `Pro until ${shortDate(plan.proUntil)}` : 'Pro (free)', sub: '', action: null };
  }
  if (plan.status === 'past_due') {
    return { label: 'Pro', sub: PLAN_COPY.cardFailingShort, action: 'update-card', danger: true };
  }
  const price = plan.interval === 'year' ? `${PRO_PRICE.year} a year` : `${PRO_PRICE.month} a month`;
  return {
    label: 'Pro',
    sub: plan.cancels ? `Ends ${shortDate(plan.proUntil)}` : `Renews ${shortDate(plan.proUntil)} · ${price}`,
    action: 'manage',
  };
}
```

```js
}

export function usePlan() {
  useSyncExternalStore(subscribe, snapshot, snapshot);

}
```

```jsx
/**
 * PlanRunner — keeps the cached plan fresh (plan.js). Renders nothing.
 * Asks at launch and whenever the app comes back to the foreground; if the
 * answer changes which mode the app should be in (Pro started or ended), the
 * app reloads, exactly as the Easy Mode switch does. Guests and store owners
 * have no plan to ask about.
 */
import { useEffect } from 'react';
import { refreshPlan } from '../../utils/plan';
import { easyModeFor } from '../../utils/easyMode';
import { STORAGE_KEYS } from '../../utils/constants';

function isGuestNow() {
  try { return localStorage.getItem(STORAGE_KEYS.GUEST_MODE) === 'true'; } catch { return false; }
}

// Module-level so the default is the same function every render (it is an effect dependency).
const reload = () => window.location.reload();

export default function PlanRunner({ role, easyMode, onModeChange = reload }) {
  useEffect(() => {
    if (role === 'store_owner' || isGuestNow()) return undefined;
    let cancelled = false;
    const run = async () => {
      const r = await refreshPlan();
      if (!cancelled && r.ok && easyModeFor(role) !== easyMode) onModeChange();
    };
    run();
    const onVisible = () => { if (document.visibilityState === 'visible') run(); };
    document.addEventListener('visibilitychange', onVisible);
    return () => { cancelled = true; document.removeEventListener('visibilitychange', onVisible); };
  }, [role, easyMode, onModeChange]);
  return null;
}
```

```js
/**
 * billing.js — paying for Keiro Pro (docs/specs/2026-10-16-pricing-design.md §2).
 *
 * The app never talks to Stripe itself: it asks Keiro's server (api/checkout,
 * api/billing-portal) for a Stripe page tied to the signed-in account and
 * opens it — the in-app browser on the iPhone, the same tab on the web.
 * Stripe sends the driver back to /?upgrade=<result> (web) or to
 * /upgrade-return.html, which hands back to the iPhone app as
 * keiro://upgrade-<result>. Either way the app re-reads its plan; it is Pro
 * only when the server says so.
 */
import { Capacitor } from '@capacitor/core';
import { EVENTS } from './constants';
import { refreshPlan } from './plan';

const PROD_ORIGIN = 'https://keiro-mutammimas-projects.vercel.app';
const RESULTS = ['done', 'cancel', 'portal'];

function apiUrl(path) {
  // The iPhone app's pages come from capacitor://localhost, which has no /api.
  return Capacitor.isNativePlatform() ? PROD_ORIGIN + path : path;
}

async function accessToken() {
  try {
    // Loaded on use: screens import this module, and the Supabase client
    // throws when imported without a configured URL (tests, CI).
    const { supabase } = await import('../services/supabase');
    const { data } = await supabase.auth.getSession();
    return data?.session?.access_token || null;
  } catch {
    return null;
  }
}

async function askForPage(path, body) {
  const token = await accessToken();
  if (!token) return { error: 'signin' };
  try {
    const res = await fetch(apiUrl(path), {
      method: 'POST',
      headers: { 'Content-Type': 'application/json', Authorization: `Bearer ${token}` },
      body: JSON.stringify({ ...body, native: Capacitor.isNativePlatform() }),
      signal: AbortSignal.timeout(15000),
    });
    const json = await res.json().catch(() => ({}));
    return res.ok && json.url ? { url: json.url } : { error: json.error || 'unavailable' };
  } catch {
    return { error: 'unavailable' };
  }
}

async function openPage(url) {
  if (Capacitor.isNativePlatform()) {
    const { Browser } = await import('@capacitor/browser');
    await Browser.open({ url });
  } else {
    window.location.assign(url);
  }
}

/** Opens Stripe's payment page for Pro, monthly or yearly. */
export async function startCheckout(interval, open = openPage) {
  const r = await askForPage('/api/checkout', { interval });
  if (r.url) await open(r.url);
  return r;
}

/** Opens Stripe's "Manage plan" page: cancel, switch, change card, receipts. */
export async function openBillingPortal(open = openPage) {
  const r = await askForPage('/api/billing-portal', {});
  if (r.url) await open(r.url);
  return r;
}

let captured = null;

/**
 * Web: main.jsx calls this before the app renders. Keeps a ?upgrade=<result>
 * left by Stripe's return and removes it from the address bar.
 */
export function captureCheckoutReturn() {
  try {
    const url = new URL(window.location.href);
    const result = url.searchParams.get('upgrade');
    if (!result) return;
    url.searchParams.delete('upgrade');
    window.history.replaceState(window.history.state, '', url.pathname + url.search + url.hash);
    captured = RESULTS.includes(result) ? result : null;
  } catch { /* no URL to read */ }
}

/** The return captured at launch (not cleared by reading it). */
export function capturedCheckoutReturn() {
  return captured;
}

export function clearCapturedCheckoutReturn() {
  captured = null;
}

/**
 * iPhone: keiro://upgrade-<result> from the return page, and closing the
 * in-app browser by hand, both re-read the plan — a lost redirect never leaves
 * the app on the old plan. No-op on the web.
 */
export function initBillingDeepLinkHandler() {
  if (!Capacitor.isNativePlatform()) return;
  Promise.all([import('@capacitor/app'), import('@capacitor/browser')]).then(([{ App }, { Browser }]) => {
```

```jsx
/**
 * UpgradeHost — mounted once in the app shell. Shows the Upgrade sheet
 * (EVENTS.OPEN_UPGRADE), the free limit sheet (EVENTS.OPEN_FREE_LIMIT), and,
 * after paying (EVENTS.CHECKOUT_RETURN 'done', or ?upgrade=done on the web),
 * "Finishing up…" until the server says Pro — at most CHECKOUT_FINISH_WAIT_MS,
 * then "we'll finish this in the background". Never shows Pro on its own word.
 */
import { useEffect, useState } from 'react';
import { EVENTS, STORAGE_KEYS, PLAN_COPY, CHECKOUT_FINISH_WAIT_MS } from '../../utils/constants';
import { refreshPlan, isPro } from '../../utils/plan';
import { capturedCheckoutReturn, clearCapturedCheckoutReturn } from '../../utils/billing';
import UpgradeSheet from './UpgradeSheet';
import FreeLimitSheet from './FreeLimitSheet';
import PlanSheet, { PrimaryBtn, TextBtn } from './PlanSheet';

function switchToNormalMode() {
  try { localStorage.setItem(STORAGE_KEYS.EASY_MODE, 'false'); } catch { /* private mode */ }
  window.location.reload();
}

function pickedProAtSignup() {
  try { return localStorage.getItem(STORAGE_KEYS.UPGRADE_AFTER_SIGNUP) === 'true'; } catch { return false; }
}

export default function UpgradeHost({ role, easyMode, onSwitchToNormal = switchToNormalMode }) {
  const [upgradeTitle, setUpgradeTitle] = useState(() => (pickedProAtSignup() ? PLAN_COPY.upgradeTitle : null));
  const [limitOpen, setLimitOpen] = useState(false);
  // null | 'finishing' | 'pro' | 'later'
  const [returnState, setReturnState] = useState(() => (capturedCheckoutReturn() === 'done' ? 'finishing' : null));

  useEffect(() => {
    // Launch-time leftovers are now in state; clear them so they show once.
    try { localStorage.removeItem(STORAGE_KEYS.UPGRADE_AFTER_SIGNUP); } catch { /* private mode */ }
    if (capturedCheckoutReturn() && capturedCheckoutReturn() !== 'done') refreshPlan();
    clearCapturedCheckoutReturn();

    const onUpgrade = (e) => { setLimitOpen(false); setUpgradeTitle(e.detail?.title || PLAN_COPY.upgradeTitle); };
    const onLimit = () => setLimitOpen(true);
    const onReturn = (e) => {
      if (e.detail?.result === 'done') { setUpgradeTitle(null); setReturnState('finishing'); }
      else refreshPlan();
    };
    window.addEventListener(EVENTS.OPEN_UPGRADE, onUpgrade);
    window.addEventListener(EVENTS.OPEN_FREE_LIMIT, onLimit);
    window.addEventListener(EVENTS.CHECKOUT_RETURN, onReturn);
    return () => {
      window.removeEventListener(EVENTS.OPEN_UPGRADE, onUpgrade);
      window.removeEventListener(EVENTS.OPEN_FREE_LIMIT, onLimit);
      window.removeEventListener(EVENTS.CHECKOUT_RETURN, onReturn);
    };
  }, []);

  useEffect(() => {
    if (returnState !== 'finishing') return undefined;
    let cancelled = false;
    let timer = null;
    const started = Date.now();
    const tick = async () => {
      await refreshPlan();
      if (cancelled) return;
      if (isPro()) { setReturnState('pro'); return; }
      if (Date.now() - started >= CHECKOUT_FINISH_WAIT_MS) { setReturnState('later'); return; }
      timer = setTimeout(tick, 2000);
    };
    tick();
    return () => { cancelled = true; clearTimeout(timer); };
  }, [returnState]);

  const closeReturn = () => setReturnState(null);
  const offerNormal = role !== 'store_owner' && easyMode;

  return (
    <>
      <UpgradeSheet key={upgradeTitle || 'closed'} open={!!upgradeTitle} title={upgradeTitle} onClose={() => setUpgradeTitle(null)} />
      <FreeLimitSheet
        open={limitOpen}
        onClose={() => setLimitOpen(false)}
        onUpgrade={() => { setLimitOpen(false); setUpgradeTitle(PLAN_COPY.upgradeTitle); }}
      />
      <PlanSheet open={!!returnState} onClose={returnState === 'finishing' ? undefined : closeReturn} label={PLAN_COPY.upgradeTitle}>
        {returnState === 'finishing' && <p style={s.body}>{PLAN_COPY.finishing}</p>}
        {returnState === 'later' && (
          <>
            <p style={s.body}>{PLAN_COPY.finishLater}</p>
            <PrimaryBtn onClick={closeReturn}>{PLAN_COPY.ok}</PrimaryBtn>
          </>
        )}
        {returnState === 'pro' && (
          <>
            <p style={{ ...s.body, fontWeight: 800, fontSize: 18 }}>{PLAN_COPY.youArePro}</p>
            {offerNormal ? (
              <>
                <p style={s.body}>{PLAN_COPY.switchToNormal}</p>
                <PrimaryBtn onClick={onSwitchToNormal}>{PLAN_COPY.switchYes}</PrimaryBtn>
                <TextBtn onClick={closeReturn}>{PLAN_COPY.switchNo}</TextBtn>
              </>
            ) : (
              <PrimaryBtn onClick={closeReturn}>{PLAN_COPY.ok}</PrimaryBtn>
            )}
          </>
        )}
      </PlanSheet>
    </>
  );
}

const s = {
  body: { margin: 0, fontSize: 15, lineHeight: 1.5 },
};
```

```js
// Stripe sends the driver here after paying, cancelling, or managing the plan
// (api/checkout, api/billing-portal). In the iPhone app's in-app browser
// (?native=1) it hands back to the app as keiro://upgrade-<result>; on the web
// it returns to the app with ?upgrade=<result>. The link is the fallback when
// the automatic hand-off is blocked. (A separate file: the CSP allows no inline script.)
(function () {
  const params = new URLSearchParams(window.location.search);
  const r = params.get('result');
  const result = r === 'done' || r === 'portal' ? r : 'cancel';
  const target = params.get('native') === '1' ? `keiro://upgrade-${result}` : `/?upgrade=${result}`;
  document.getElementById('back').setAttribute('href', target);
  window.location.replace(target);
})();
```

```jsx
/**
 * PlanSetting — Settings → Plan, for signed-in drivers
 * (docs/specs/2026-10-16-pricing-design.md §4). Free shows the month's count
 * and Upgrade; Stripe Pro shows renewal and Manage plan (Update card while a
 * card is failing); the owner's switch shows "Pro (free)" / "Pro until …".
 */
import { useState } from 'react';
import { ACCENT } from '../../theme';
import { Section, Row } from '../ui/SettingsUI';
import { PLAN_COPY, STORAGE_KEYS } from '../../utils/constants';
import { planSummary, openUpgrade } from '../../utils/plan';
import { usePlan } from '../../hooks/usePlan';
import { openBillingPortal } from '../../utils/billing';

function isGuestNow() {
  try { return localStorage.getItem(STORAGE_KEYS.GUEST_MODE) === 'true'; } catch { return false; }
}

const BUTTON = { upgrade: PLAN_COPY.upgrade, manage: PLAN_COPY.manage, 'update-card': PLAN_COPY.updateCard };

export default function PlanSetting({ role, C }) {
  const plan = usePlan();
  const [busy, setBusy] = useState(false);
  const [error, setError] = useState('');
  if (role === 'store_owner' || isGuestNow()) return null;

  const v = planSummary(plan);

  async function act() {
    if (v.action === 'upgrade') { openUpgrade(); return; }
    setBusy(true);
    setError('');
    const r = await openBillingPortal();
    setBusy(false);
    if (r.error) setError(PLAN_COPY.portalError);
  }

  return (
    <Section title="Plan" C={C} defaultOpen>
      <Row label={v.label} sub={v.sub ? <span style={{ color: v.danger ? C.danger : undefined }}>{v.sub}</span> : null} C={C}>
        {v.action && (
          <button type="button" onClick={act} disabled={busy}
            style={{ ...s.btn, background: v.action === 'upgrade' ? ACCENT : C.rowBg, color: v.action === 'upgrade' ? '#fff' : ACCENT, border: `1px solid ${C.divider}` }}>
            {busy ? '…' : BUTTON[v.action]}
          </button>
        )}
      </Row>
      {error && <p role="alert" style={{ color: C.danger, fontSize: 12, margin: '0 0 10px' }}>{error}</p>}
    </Section>
  );
}

const s = {
  btn: { flexShrink: 0, minHeight: 36, padding: '0 14px', borderRadius: 10, fontSize: 13, fontWeight: 700, cursor: 'pointer' },
};
```

```js
/**
 * Pure rules for the Pro record (supabase-pricing.sql `subscriptions`),
 * shared by the three billing functions.
 */

/** A Stripe subscription that still makes the account Pro. */
export function isActiveStripeRow(row, now = Date.now()) {
  return row?.source === 'stripe'
    && ['active', 'past_due'].includes(row.status)
    && Boolean(row.pro_until) && Date.parse(row.pro_until) > now;
}

/** The owner's "free forever" switch. */
export function isFreeForever(row) {
  return row?.source === 'manual' && row.pro_until == null;
}

/** A Stripe subscription → the row the webhook writes. */
export function rowFromSubscription(sub) {
  const item = sub.items?.data?.[0];
  // Newer Stripe API versions keep the period on the item; older ones on the subscription.
  const periodEnd = item?.current_period_end ?? sub.current_period_end;
  return {
    user_id: sub.metadata?.user_id || null,
    source: 'stripe',
    status: sub.status,
    pro_until: periodEnd ? new Date(periodEnd * 1000).toISOString() : null,
    interval: item?.price?.recurring?.interval ?? null,
    cancels: Boolean(sub.cancel_at_period_end || sub.cancel_at),
    stripe_customer_id: typeof sub.customer === 'string' ? sub.customer : sub.customer?.id ?? null,
    stripe_subscription_id: sub.id,
    updated_at: new Date().toISOString(),
  };
}

/**
 * Whether the webhook may write `incoming` over `existing`: never over free
 * forever, and never let an older subscription that is no longer active
 * replace a different one that is.
 */
export function shouldWrite(existing, incoming, now = Date.now()) {
  if (isFreeForever(existing)) return false;
  if (existing?.source === 'stripe'
      && existing.stripe_subscription_id !== incoming.stripe_subscription_id
      && isActiveStripeRow(existing, now)
      && !isActiveStripeRow(incoming, now)) return false;
  return true;
}

/** Where Stripe sends the driver back (public/upgrade-return.js hands the iPhone app its keiro:// link). */
export function returnUrl(origin, native, result) {
  return native ? `${origin}/upgrade-return.html?result=${result}&native=1` : `${origin}/?upgrade=${result}`;
}
```

```js
/**
 * api/checkout.js — a Stripe payment page for Keiro Pro, tied to the caller.
 *
 *   POST /api/checkout   Authorization: Bearer <Supabase access token>
 *        { interval: 'month' | 'year', native?: boolean }
 *     200 { url }               open it (iPhone: in-app browser; web: same tab)
 *     400 { error: 'interval' }
 *     401 { error: 'signin' }
 *     409 { error: 'already_pro' }   active Stripe subscriber, or free forever
 *     502 { error: 'unavailable' }
 * The subscription carries the Keiro user id (metadata) so api/stripe-webhook
 * knows whose Pro record to write.
 */
import { getStripe } from './_lib/stripe.js';
import { userFromRequest, getSubscriptionRow } from './_lib/supabaseAdmin.js';
import { isActiveStripeRow, isFreeForever, returnUrl } from './_lib/planRows.js';
import { reply, preflight, readJson } from './_lib/http.js';
import { env } from './_lib/env.js';

export function OPTIONS() {
  return preflight();
}

export async function POST(request) {
  const user = await userFromRequest(request);
  if (!user) return reply(401, { error: 'signin' });
  const body = await readJson(request);
  const price = body.interval === 'month' ? env('STRIPE_PRICE_MONTHLY')
    : body.interval === 'year' ? env('STRIPE_PRICE_YEARLY') : '';
  if (!price) return reply(400, { error: 'interval' });
  try {
    const existing = await getSubscriptionRow(user.id);
    if (isActiveStripeRow(existing) || isFreeForever(existing)) return reply(409, { error: 'already_pro' });
    const origin = new URL(request.url).origin;
    const native = body.native === true;
    const session = await getStripe().checkout.sessions.create({
      mode: 'subscription',
      line_items: [{ price, quantity: 1 }],
      client_reference_id: user.id,
      subscription_data: { metadata: { user_id: user.id } },
      ...(existing?.stripe_customer_id ? { customer: existing.stripe_customer_id } : { customer_email: user.email }),
      success_url: returnUrl(origin, native, 'done'),
      cancel_url: returnUrl(origin, native, 'cancel'),
    });
    return reply(200, { url: session.url });
  } catch (err) {
    console.error('checkout failed', err?.message);
    return reply(502, { error: 'unavailable' });
  }
}
```

- [ ] **Step 6: `api/stripe-webhook.js`**

```js
/**
 * api/stripe-webhook.js — Stripe tells Keiro about payments, renewals, failed
 * cards and cancellations; this writes the Pro record (supabase-pricing.sql).
 *
 * Only messages carrying Stripe's signature are accepted (400 otherwise). On
 * every handled event the subscription is re-read from Stripe and its CURRENT
 * state written, so repeated or out-of-order events are harmless. 500 makes
 * Stripe retry later.
 */
import { getStripe } from './_lib/stripe.js';
import { getSubscriptionRow, saveSubscriptionRow } from './_lib/supabaseAdmin.js';
import { rowFromSubscription, shouldWrite } from './_lib/planRows.js';
import { env } from './_lib/env.js';

function subscriptionIdOf(event) {
  const o = event.data?.object ?? {};
  if (event.type === 'checkout.session.completed') {
    if (o.mode !== 'subscription') return null;
    return typeof o.subscription === 'string' ? o.subscription : o.subscription?.id ?? null;
  }
  if (typeof event.type === 'string' && event.type.startsWith('customer.subscription.')) return o.id ?? null;
  return null;
}

export async function POST(request) {
  const stripe = getStripe();
  const body = await request.text();
  let event;
  try {
    event = await stripe.webhooks.constructEventAsync(body, request.headers.get('stripe-signature') || '', env('STRIPE_WEBHOOK_SECRET'));
  } catch {
    return Response.json({ error: 'bad signature' }, { status: 400 });
  }

  const subscriptionId = subscriptionIdOf(event);
  if (!subscriptionId) return Response.json({ received: true });

  try {
    const row = rowFromSubscription(await stripe.subscriptions.retrieve(subscriptionId));
    if (!row.user_id && event.type === 'checkout.session.completed') {
      row.user_id = event.data.object.client_reference_id ?? null;
    }
    if (!row.user_id) {
      console.error('stripe-webhook: no Keiro user on', subscriptionId);
      return Response.json({ received: true });
    }
    const existing = await getSubscriptionRow(row.user_id);
    if (shouldWrite(existing, row)) await saveSubscriptionRow(row);
    return Response.json({ received: true });
  } catch (err) {
    console.error('stripe-webhook failed; Stripe will retry', err?.message);
    return Response.json({ error: 'retry' }, { status: 500 });
  }
}
```

```js
// Pricing screens as a signed-in driver sees them (dev bypass; plan states seeded).
const { chromium } = require('/Users/muti/.npm/_npx/d71ea5ed3eabc9b3/node_modules/playwright');
const [S, SITE = 'http://localhost:5173'] = process.argv.slice(2);
const month = (() => { const d = new Date(); return `${d.getFullYear()}-${String(d.getMonth() + 1).padStart(2, '0')}`; })();
const PLANS = {
  free15: { pro: false, usedThisMonth: 15, month },
  free20: { pro: false, usedThisMonth: 20, month },
  proMonthly: { pro: true, source: 'stripe', status: 'active', interval: 'month', cancels: false, proUntil: '2099-11-16T12:00:00Z', usedThisMonth: 3, month },
  pastDue: { pro: true, source: 'stripe', status: 'past_due', interval: 'month', cancels: false, proUntil: '2099-11-16T12:00:00Z', usedThisMonth: 3, month },
  forever: { pro: true, source: 'manual', status: 'active', proUntil: null, usedThisMonth: 3, month },
};
async function open(browser, plan) {
  const page = await (await browser.newContext({ viewport: { width: 390, height: 844 }, serviceWorkers: 'block' })).newPage();
  await page.addInitScript((p) => {
    localStorage.setItem('inv_plan_cache', JSON.stringify(p));
    localStorage.setItem('inv_tour_seen_easy', '1');
    localStorage.setItem('inv_tour_seen_full', '1');
  }, plan);
  await page.goto(SITE, { waitUntil: 'networkidle' });
  await page.waitForTimeout(1500);
  for (const t of ['Continue without account (dev)', 'Delivery Driver', 'Get Started']) {
    await page.locator(`button:has-text("${t}")`).first().click({ timeout: 3000 }).catch(() => {});
    await page.waitForTimeout(900);
  }
  await page.locator('button:has-text("Skip")').first().click({ timeout: 2000 }).catch(() => {});
  return page;
}
(async () => {
  const browser = await chromium.launch();
  // 15 used: the Easy invoice shows "5 free invoices left".
  let page = await open(browser, PLANS.free15);
  await page.locator('[data-qs="new-invoice"]').first().click();
  await page.waitForTimeout(800);
  console.log('left line:', await page.locator('text=/free invoices? left this month/').first().innerText().catch(() => 'MISSING'));
  await page.screenshot({ path: `${S}/pricing-left.png` });
  // 20 used: + New opens the limit sheet; Upgrade opens the Upgrade sheet.
  page = await open(browser, PLANS.free20);
  await page.locator('[data-qs="new-invoice"]').first().click();
  await page.waitForTimeout(600);
  console.log('limit sheet:', await page.locator('text=You\'ve used your 20 free invoices this month').count());
  await page.screenshot({ path: `${S}/pricing-limit.png` });
  await page.locator('button:has-text("Upgrade")').first().click();
  await page.waitForTimeout(400);
  console.log('upgrade sheet prices:', await page.locator('text=$4.99 a month').count(), await page.locator('text=/\\$49.99 a year/').count());
  await page.screenshot({ path: `${S}/pricing-upgrade.png` });
  // Settings → Plan in each state.
  for (const [name, plan] of Object.entries(PLANS)) {
    page = await open(browser, plan);
    await page.locator('button[aria-label="Open menu"]').first().click();
    await page.waitForTimeout(500);
    await page.locator('button:has-text("Settings")').first().click();
    await page.waitForTimeout(800);
    const plansection = await page.locator('text=Plan').first().locator('xpath=ancestor::div[3]').innerText().catch(() => 'MISSING');
    console.log(`settings ${name}:`, JSON.stringify(plansection.slice(0, 160)));
    await page.screenshot({ path: `${S}/pricing-settings-${name}.png` });
  }
  await browser.close();
})();
```
